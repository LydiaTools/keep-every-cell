What is checked, and what stays yours?

This tool checks table structure and your chosen number columns, not whether AI-generated facts are true. It handles one small pipe-delimited Markdown table. It does not read PDF, CSV, images or existing Excel files. Text columns keep their literal values; number conversion is your choice.

UTF-8 input: 256 KiB, 1,000 data rows, 32 header columns, 20,000 data cells. Preview shows the first 50 rows. Input is not saved after reload; download your review if you need it later.
