# Keep Every Cell｜AI 表格校对台

**一行有四格，不能直接当作三列表格。**

把 AI 生成的 Markdown 表格交给 Excel 前，先核对列是否对齐。额外内容保留可见，
修法由你选择；编号默认保留文本，数量列再明确选数字。中英文界面，不需账号、
上传或模型 API。

[English](README.md) · [源码](https://github.com/LydiaTools/keep-every-cell)

## 怎么用

打开源码包中的 `index.html`，不需要构建或安装依赖。

1. 点击“试用有问题的示例”，或粘贴一个 Markdown 表格。
2. 查看问题行。原创示例的第 3 行应选择合并 **2 + 3 格**，将 `Cedar | Oak`
   明确保留在同一格；也可以直接修改原文。
3. 编号列保留“文本”；需要计算的数量列再选“数字”。
4. 下载 `.xlsx`，或保存包含当前原文、格子、问题、列类型及明确合并记录的核对 JSON。

多格行不会被截断或自动扩成新列，少格行不会自动补空；问题未解决前禁止导出 Excel。
工具不替你猜哪两格本来属于一起。

## 数据怎么处理

- 文本列将 `0017`、长编号、`=2+2` 等保留为字符串。
- 数字列由你选择，只接受最多 15 位有效数字的普通小数。不支持的值会阻止导出。
  数字转换可能改变原本写法或显示，不自动识别日期或公式。
- 页面把用户 HTML 当普通文字显示。JSON 使用数组，重复或空表头不会覆盖格子。
- 所有处理在当前标签页进行，无运行依赖、统计或网络客户端；连接被 CSP 限制。
  网站本身仍涉及普通页面和静态文件请求，不把内容写进 URL。

刷新后不恢复输入，需续作时下载核对文件；里面包含你选择保存的原文，私人资料应自行保管。

## 验证与范围

[CI 实际结果](https://github.com/LydiaTools/keep-every-cell/actions/workflows/checks.yml)
包含核心检查、真实浏览器修补/下载、离线文件入口和 openpyxl 工作簿回读。
命令与依赖见英文 README。不能只凭存在 workflow 文件就称验证通过。

支持单个竖线 Markdown 表格、可选外侧竖线，以及包住整段表格的 `markdown` 代码围栏。
一般代码块不导入。Markdown 样式保留为字面文字；前后说明留在原文，明确不写入工作簿。
不是完整 GFM 渲染器，不解析 PDF、OCR、CSV 或现成 Excel，也不核实 AI 生成事实。

输入限制：UTF-8、256 KiB、1,000 行数据、32 列表头、20,000 个数据格，单格最多
32,767 字符。预览前 50 行，超限阻止导出，不部分生成。Chromium 与 openpyxl 检查
不能代表原生 Excel、Numbers、Safari 或读屏软件验收。

它提供更严格的校对流程，不声称其他转换器都会丢数据。实看的网页转换器保留了多出的值，
但会扩列并允许导出；可选 tablemd 0.1.0 对照是一个原创合成案例，不是准确率排名。
[方法与来源](docs/method.md)。没有承诺采用、收益或 Star 数量。
